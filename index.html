Notes · Exact Scanner Rules

主状态按 Fakeout → Breakout → Holding → Setup → Watch 判定，每只股票只能有一个主状态；Spring 只作为额外标签。

Tightness · 15D Range

(15日最高价 − 15日最低价) ÷ 最新收盘价 ×100。筛选器可选择 ≤8%、≤12% 或 ≤16%；越小越紧。

Setup

收盘 > SMA20 和 SMA50；距离此前20日最高价为0–5%；15D Range ≤12%；三个月涨幅 >8%。

Breakout

收盘 > 此前20日最高价；当日量 ÷ 前50日均量 ≥1.5；收盘位置 (收盘−最低)÷(最高−最低) ≥60%。

Holding

过去10日出现有效 Breakout；最新收盘 ≥ breakout pivot；最新收盘 ≥ 21EMA ×98%。

Fakeout

当日最高刺穿 pivot 但收盘 < pivot；或过去10日出现有效 Breakout、最新收盘跌回 pivot 下方。

Spring · Secondary Tag

跌破此前约30日支撑至少1%并收回；随后1–5日成交量 >50日均量×1.15，且涨幅≥4%或收复短期高点。它不改变主状态。

Universe 要求50日平均每日成交额 ≥ $20M。Cluster Score 用于集中注意力，不是买入信号。
